

# **Introducción al software**



## ¿Qué es un programa informático?

Un **programa informático** es un conjunto de instrucciones ordenadas y estructuradas escritas en un lenguaje de programación, que le indican a una computadora u ordenador qué tareas debe realizar de forma automática para resolver un problema o procesar datos.







## Diferencia entre código fuente, código objeto y código ejecutable



**Código fuente:** Es el código escrito por el programador utilizando un lenguaje de programación accesible para las personas (como Python, C++ o Java). No puede ser ejecutado directamente por el procesador.

**Código objeto:** Es el código intermedio resultante de traducir o compilar el código fuente a lenguaje máquina (ceros y unos). Aunque está formateado para el sistema, aún no es un programa completo o directamente utilizable sin vincular.

**Código ejecutable:** Es el archivo final listo para que el sistema operativo lo procese e interprete directamente (por ejemplo, archivos con extensión `.exe` en Windows o `.bin` en Linux).







## Etapas del desarrollo del software



1. **Análisis de requisitos:** Se identifican las necesidades del usuario o del cliente y se define qué debe hacer el software.

2. **Diseño:** Se planifica la arquitectura, la interfaz y la estructura interna del programa.

3. **Implementación / Codificación:** Fase en la que se escribe el *código fuente* del programa.

4. **Pruebas:** Se verifica el correcto funcionamiento del software y se corrigen posibles errores o fallos.

5. **Despliegue e Instalación:** Se entrega y pone a disposición del usuario el programa (*código ejecutable*).

6. **Mantenimiento:** Se actualiza y mejora el software a lo largo del tiempo.
